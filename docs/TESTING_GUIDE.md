# دليل اختبار «دفتري» — كل المهام والأمان ونقل البيانات

اختبر بالترتيب. ضع ✅ أو ❌ بجانب كل بند، وإن ظهر ❌ اكتب رقم البند وما حدث وأرسله لي (مع لقطة شاشة إن أمكن).

> **قبل البدء:** شغّل التطبيق من Android Studio (انظر [ANDROID_STUDIO.md](ANDROID_STUDIO.md)).
> القسم **أ** يبدأ من تطبيق جديد فارغ، ثم أدخل بيانات للاختبار يدوياً (القسم **ب**).
> لإعادة التطبيق كأنه جديد: **المزيد ← حذف جميع البيانات**، أو احذف التطبيق من المحاكي وشغّله من جديد.

### فحص تقني اختياري (Device Explorer)

- قاعدة البيانات في `/data/data/com.daftry.daftry/` ولا يمكن الوصول إليها من تطبيقات أخرى (مساحة خاصة بالتطبيق).
- رمز PIN **غير مخزّن كنص**: يُحفظ في Android Keystore كبصمة PBKDF2 (يفحصها اختبار الجهاز الآلي).

| M5 | Device Explorer ← `/sdcard/Download` ← انقر بالزر الأيمن على الملف ← Save As إلى الحاسوب، وافتحه بمحرر نصوص | **محتوى غير مقروء** (يبدأ بـ `DAFTRY01` ثم بيانات مشفّرة) — لا أسماء ولا مبالغ |
| M6 | «استيراد ملف نسخة» ← اختر الملف ← كلمة مرور **خاطئة** | «كلمة المرور خاطئة أو الملف تالف»، **ولا تتغير بياناتك** |
| M7 | استورد ملفاً ليس نسخة (مثلاً صورة أو PDF) | «الملف ليس نسخة دفتري صالحة» |
| M8 | **محاكاة جهاز جديد:** المزيد ← حذف جميع البيانات | يعود لشاشة اختيار العملة |
| M9 | في شاشة العملة ← «لديك نسخة احتياطية؟ استعادة» ← اختر الملف ← كلمة المرور الصحيحة | «تمت الاستعادة بنجاح» ويدخل الرئيسية مباشرة |
| M10 | قارن بأرقام M1 | **مطابقة تماماً**: الأرصدة، المعاملات، الديون والدفعات، الميزانيات، الفئات، الأشخاص |
| M11 | المزيد ← إعادة احتساب الأرصدة | «صُحح 0 حساب» |
| M12 | اللغة والمظهر | تأتي من النسخة؛ أما القفل وإعدادات النسخ فتبقى كما هي في الجهاز |
| M13 | الاستعادة فوق بيانات موجودة (دون حذف) | تأكيد «ستُستبدل كل البيانات الحالية…» ثم الاستبدال |

> **قيد معروف:** النسخة تحمل قاعدة البيانات كاملة (كما تنص الوثيقة) **دون صور الإيصالات**. على نفس الجهاز تبقى الصور موجودة؛ أما على جهاز آخر فتنتقل المعاملة ويظهر مكان الصورة رمز «صورة غير متوفرة».
